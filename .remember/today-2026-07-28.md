# 2026-07-28
- Fixed BUG-028: Ethernet cable replug hard-fault. The root cause was an lwIP double-add assertion on `mdns_resp_add_netif` triggered after DHCP rebound on link up. Resolved by maintaining a boolean flag to only add the netif and service once, using `mdns_resp_netif_settings_changed` for IP updates.
- Fixed BUG-029: Host `UdpSource` stream recovery failed after reconnect because fallback keepalives were being broadcast to `255.255.255.255`, which misroutes on some Linux configs. Updated the read loop to actively re-query mDNS every keepalive interval when the stream goes dead.
