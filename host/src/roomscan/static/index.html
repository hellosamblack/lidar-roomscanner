A correct calibration reports the same field magnitude in every orientation, so fitting one needs samples from the whole sphere of directions. The shell below is that sphere, drawn in the device's own frame — it does not move, so a gap stays where you last saw it. Dashed hollow rings are the angles you are still missing; a solid disc's size is how many samples it holds. Press Start and turn the device to sweep the bright marker over the holes.
