## BUG-090 — View mode can show live data instead of the loaded capture

**Date filed:** 2026-08-07  
**Area:** host/web  
**Status:** open

In View mode, Point cloud, SLAM, Stream, Sensors, or IR monitor can show the current
live stream rather than the loaded capture. View mode must be capture-scoped: every
listed display and sensor panel shows only the loaded capture, despite asynchronous
live packets arriving in the background. Add an end-to-end regression covering each
display.
