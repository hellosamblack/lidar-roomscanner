# BUG-098 — Preview mode shows vertical point cloud instead of horizontal floorplan

**Date filed:** 2026-08-08  
**Status:** open  
**Area:** host/web UI (View mode, preview display)  

## Summary

In View mode, the preview thumbnail is displayed as a vertical (upright) point cloud instead of a horizontal (top-down) floorplan view. When preview represents a floorplan, it should be oriented horizontally and scaled appropriately to show the room layout from above.

## Observation

- When loading a capture and viewing it in preview mode, the point cloud is rendered standing upright (portrait orientation)
- The scaling and framing make it difficult to interpret as a floor plan or room layout
- A top-down (bird's-eye) orthographic view would be more intuitive for floorplan-style previews
- Horizontal scaling should reflect the actual room dimensions proportionally

## Expected behavior

1. The preview display should use a **top-down orthographic projection** (bird's-eye view)
2. The point cloud should be rotated to show **horizontal orientation** (gravity-aligned, looking down)
3. **Aspect ratio and scaling** should match the room's actual proportions (not distorted)
4. This provides an intuitive floorplan-style visualization suitable for room planning

## Root cause

Unknown. Suspected areas:
- The preview camera uses a 3D perspective view instead of orthographic projection
- The point cloud is not being rotated to gravity-aligned horizontal orientation
- The camera framing is set to World or FPV mode instead of a floorplan-specific view
- Aspect ratio scaling may not account for the room's footprint

TBD — requires switching the preview camera to orthographic projection, rotating the point cloud to horizontal orientation, and scaling the view to the room's footprint dimensions.
