# BUG-096 — Oscillate orbit mode non-functional and slider always enabled

**Date filed:** 2026-08-08  
**Status:** open  
**Area:** host/web UI (View panel, camera controls)  

## Summary

The "Oscillate" orbit mode toggle in the View panel does nothing — enabling oscillation produces no visible camera motion. Additionally, the oscillation amplitude slider remains enabled regardless of whether oscillate mode is active; it should be disabled when oscillate mode is off.

## Observation

- The Oscillate toggle control exists and responds to clicks
- No camera oscillation occurs when toggled on
- The oscillation amplitude slider is always interactive, even when oscillate mode is disabled
- The slider should be visually and functionally disabled (grayed out, non-interactive) when oscillate mode is off

## Expected behavior

1. When Oscillate is toggled **on**: the camera should autonomously oscillate (triangle wave ±N degrees) about the current azimuth
2. When Oscillate is toggled **off**: the camera should hold a fixed azimuth without oscillation
3. The oscillation amplitude slider should only be enabled/interactive when Oscillate mode is active

## Root cause

Unknown. Suspected areas:
- The oscillate-mode state is not being passed to the camera controller / SLAM orbit logic
- The orbit oscillation is not being applied in the scene's animation loop
- The slider's disabled state is not being bound to the oscillate toggle's state in the UI

## Resolution

TBD — requires inspection of the orbit camera logic in `slam.js`, the View panel's oscillate control binding, and the connection between the UI state and the animation loop.
