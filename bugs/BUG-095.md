# BUG-095 — Splat mode transparency slider non-functional

**Date filed:** 2026-08-08  
**Status:** open  
**Area:** host/web UI (SLAM/splat display mode)  

## Summary

In splat visualization mode, the "see-through" (transparency) slider in the View panel has no effect on the rendered Gaussian splats — adjusting the slider produces no visible change to the opacity/alpha of the splat geometry.

## Observation

When displaying a Gaussian splat reconstruction (Splat display mode in the web UI):
- The transparency slider is present and responds to interaction
- No visual change occurs when the slider value is adjusted
- The splat geometry remains at a fixed opacity regardless of slider position

Compare to Point Cloud and SLAM mesh modes, where the transparency slider functions correctly.

## Root cause

Unknown. Suspected areas:
- The splat material's alpha channel is not wired to the UI state change
- The transparency value is not being passed to `slam.js`'s splat geometry rendering
- The WebGL material opacity uniform is not being updated on slider changes

## Resolution

TBD — requires inspection of the splat material setup in `slam.js`, the `/ws` state message handler, and the connection between the View panel's slider value and the CUDA/WebGL rendering pipeline.
