## BUG-084 — SLAM forks into a second, vertically displaced set of rooms near frame 979

**Date filed:** 2026-08-06  
**Area:** host/slam  
**Status:** open (reproducible from the supplied capture; root cause unknown)

## Symptom

`captures/officeFullScanAug6.bin` contains a catastrophic SLAM discontinuity at
approximately frame **979**. The mapper places the ceiling substantially lower than the
ceiling it had already detected earlier in the scan. The resulting map is not merely
slightly warped: the Detailed SLAM reconstruction shows a separate, internally coherent
set of rooms rather than the same room layout continued from the earlier trajectory.

The ceiling-height jump and the second-room-set result indicate a map fork, relocalization
failure, or similarly terminal pose discontinuity. They should be investigated together;
the Detailed result independently exposes the failure even if the live preview makes the
transition difficult to see.

## Reproduction

1. Load `captures/officeFullScanAug6.bin`.
2. Run SLAM through the capture, including frames around 979.
3. Compare the ceiling height before and after the discontinuity.
4. Run the same capture through Detailed SLAM and compare its room layout with the map
   established before frame 979.

## Expected behavior

The ceiling should remain at the previously established physical height, and the scan
should continue in the same world/map. If tracking confidence is insufficient to maintain
that estimate, SLAM should reject or clearly flag the transition rather than silently
creating a second set of rooms at a different elevation.

## Impact

The capture's reconstruction is unusable across the discontinuity. A visually plausible
but vertically displaced map can contaminate room dimensions and any downstream mesh or
measurement, while the separate Detailed room set makes the failure look like valid new
geometry rather than an explicit tracking loss.

## Investigation notes

- The first reported onset is around frame 979; determine the exact last-good and first-bad
  frames during analysis.
- Compare raw and fused orientation priors, ICP fitness/correspondences, tracking-lost
  gates, barometer authority, and pose increments across the boundary.
- Check whether the live and Detailed paths diverge at the same frame or whether one path
  is masking an earlier pose error.
- Do not infer a physical second room set from the Detailed mesh until the pose trajectory
  has been checked for a discontinuity.
