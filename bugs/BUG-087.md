## BUG-087 — Every capture shows the same tooltip text

**Date filed:** 2026-08-07  
**Area:** host/web UI  
**Status:** open

The tooltip shown for every item in the Captures pane is identical, so it does not
identify or explain the capture being hovered. Each capture should expose its own
name, metadata, or action description. Inspect the capture-row data binding and add a
regression test with two captures having different tooltip content.
