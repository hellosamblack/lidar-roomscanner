## BUG-091 — Ephemeral SLAM playback is non-deterministic when seeking

**Date filed:** 2026-08-07  
**Area:** host/slam  
**Status:** open

Rewinding or fast-forwarding a capture while using ephemeral SLAM can produce a
different result for the same capture and seek position. Seeking must reset all
ephemeral SLAM state and replay identical input bytes/settings identically. Identify
state that survives a seek and add a repeat-seek determinism test.
